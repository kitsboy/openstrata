- Login has failure-counting rate limiting (429 + retry-after, success clears); invite-only accounts still pending before public exposure
- The live site remains a fully functional front-end product demo; legal/statutory content awaits professional review
- Landing page now a standalone dashboard shell with real links; the marketing header/footer appears on all non-home pages only
- CSP `connect-src` allows `https:` by default for the configurable live-API origin — the prebuild script pins it to an explicit origin when `CSP_API_ORIGIN`/`PUBLIC_API_BASE_URL` is set

- The frontend API client is built and documented, but no backend is reachable yet: the host deploy is still pending, and the API-exposure path (Tailnet-only vs public behind auth + CORS) is decided at deploy time via `PUBLIC_API_BASE_URL`
